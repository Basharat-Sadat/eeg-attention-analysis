# EEG Attention Analysis

## Overview
This project explores relationships between EEG frequency-band measurements and attention scores using Python. The goal is to practice data analysis and visualization while investigating how patterns in EEG data vary across subjects and videos.

## Research Question
Are EEG frequency-band measurements associated with attention scores, and do these relationships differ across individuals?

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Status
Exploratory data analysis is in progress. The project includes data cleaning, descriptive statistics, correlation analysis, and visualizations.

## Note
This is an educational exploratory analysis. Correlations do not establish causation, and results should be interpreted with consideration for differences between subjects and potential data-quality limitations.
